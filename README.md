# CarePlus Multispeciality Hospital Website

Open `index.html` in a modern browser.

## Included
- Responsive premium healthcare landing site
- Sticky navigation and appointment CTA
- Hero, trust, about, departments, doctors, services, facilities
- Emergency, appointment, patient information, testimonials, contact and footer
- Accessible labels, focus styles, semantic sections and responsive layout
- Client-side appointment form validation/demo handling
- Editable placeholders for hospital-specific contact data and doctor credentials

## Important
The supplied specification requires original generated photography and prohibits stock images. The current build uses temporary remote image references so the site is immediately previewable. Replace these with approved original/generated assets before production.

No hospital phone numbers, addresses, doctor credentials, patient claims, statistics or testimonials have been invented.
